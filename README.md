## Featured Project

### [ManifestLE](https://github.com/sprayberry210-afk/ManifestLE)

A Windows desktop evidence and property management prototype built with C#, WPF, Entity Framework Core, and SQLite.

The application supports:

- Separate registers for evidence, found property, and safekeeping
- Multiple individually numbered items within a case
- Property intake and hierarchical storage locations
- Item-level chain of custody, including transfers, check-outs, and check-ins
- Inventory audits with recorded findings and locked completion
- Searchable application audit history
- Password authentication, authenticator-based MFA, and role checks

**Status:** Active development  
**Testing:** 43 passing automated tests at the latest verified milestone

[View the source, screenshots, and setup instructions →](https://github.com/sprayberry210-afk/ManifestLE)

ManifestLE is a development prototype using fictional demonstration data.
